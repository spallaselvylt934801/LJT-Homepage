# LJT-Homepage

Personal academic homepage of **Junteng Liu**, first-year PhD candidate at the HKUST NLP Group. Built with the [Academic Pages template](https://github.com/academicpages/academicpages.github.io) and hosted on GitHub Pages.

## Content

- `_pages/about.md` — About page with personal details, academic background, research experience, the full publication list, awards, and contact information.
- `_publications/` — one Markdown file per publication, rendered on the Publications page.
- `_config.yml` — site-wide settings and the author profile shown in the sidebar.
- `_data/navigation.yml` — header navigation (About, Publications).

The site is built and deployed to GitHub Pages by the workflow in `.github/workflows/jekyll.yml` on pushes to `master`.
